Paint

A simple, easy-to-use image editor for Linux. Open a picture, draw on it, save it, and get on with your day.

Download for Linux AppImage & other downloads

paint_0.1.0_amd64.deb · 8.5M · 64-bit Debian package

Install with apt

Adds the signed repository, so apt upgrade keeps Paint current along with everything else on the machine.

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://rbuache.github.io/paint/paint-archive-keyring.gpg \
  | sudo tee /etc/apt/keyrings/paint.gpg > /dev/null
sudo curl -fsSL -o /etc/apt/sources.list.d/paint.sources \
  https://rbuache.github.io/paint/paint.sources
sudo apt update
sudo apt install paint

Updating

sudo apt update && sudo apt upgrade

Or install the single file

No repository, and no automatic updates.

sudo apt install ./paint_0.1.0_amd64.deb

What it does

  • Draw — pencil, brush, eraser, fill, shapes, text
  • Select — rectangular and free-form, move and resize
  • Transform — flip, rotate, resize, stretch and skew
  • Undo — bounded by memory, not by three steps
  • Files — PNG, JPEG, BMP, GIF, TIFF, TGA, ICO and more
  • Clipboard — copy a sketch straight into a chat

Everything happens locally: no accounts, no network, no telemetry. Built against glibc 2.35, so it runs on Ubuntu 22.04+, Debian 12+ and anything newer.
